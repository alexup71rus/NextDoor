# NextDoor / «За стеной»

Нативное menu bar-приложение для macOS 26, которое пропускает системный звук через low-pass EQ, отдельное усиление баса, приглушённое эхо и комнатную реверберацию.

У каждого эффекта честный ноль; при всех нулевых эффектах системный поток проходит без обработки. Отдельный ползунок усиления компенсирует потерю воспринимаемой громкости, не заставляя повышать общую громкость macOS.

Настройки автоматически сохраняются как «Последний». Текущую комбинацию можно сохранить под своим названием и затем выбрать из списка пресетов.

В меню «Источник» можно обработать весь системный звук или только выбранное приложение. Electron-приложения и браузеры группируются вместе со своими аудио helper-процессами. Если нужного приложения нет в списке, запустите его и нажмите «Обновить список».

## Первый запуск

1. Откройте `NextDoor.xcodeproj` в Xcode.
2. Выберите схему `NextDoor` и нажмите Run.
3. Нажмите значок волны в строке меню и включите эффект.
4. Разрешите **System Audio Recording**, когда macOS покажет системный запрос.

После сборки Xcode control «За стеной» можно добавить через режим редактирования Control Center. В Control Center он работает как кнопка; ползунки доступны из иконки в строке меню, потому что WidgetKit не предоставляет сторонним controls произвольный slider.

## Безопасный bypass

Приложение использует `CATapMutedWhenTapped`: исходный звук глушится только пока приложение действительно читает системный поток. При выключении эффекта или завершении приложения tap и временное aggregate-устройство удаляются.
